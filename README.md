# 国际影像展陈协调器（平遥摄影大展后端）

管理数千名摄影师的照片、短视频、手工书与实验影像在古城展厅、街巷、院落之间的展陈协调：作品组成件、权利人声明、借展协议、场地条件、设备资源、安装依赖与只追加运营台账。纯 Go 标准库实现，零外部依赖，内存事实库 + 只增事件台账（接口可替换为持久化实现）。

## 能力

- **作品与组成件**：实体相框/装置/手工书参与占用冲突；数字播放文件不产生实体占用，但校验播放规格。
- **权利声明**：按国家/地区、媒介、日期窗口控制公开展示；撤回只影响失去覆盖的未结束排期。
- **借展协议**：排期必须落在借展窗口内，结束不得晚于撤展时间。
- **场地与设备**：场地接受媒介与必需条件（如暗房、供电）必须由分配设备满足；场地关闭后拒绝一切新排期。
- **排期确认**：半开区间重叠检测（同一实体件/设备不得重复占用），确认时复验全部规则且安装前置项全部解决。
- **安装前置项**：运输到场、保险生效、公开展示许可、安装班组、数字件现场试播（依赖班组），由运营事件驱动闭环。
- **临时换场**：未开始的已确认排期可换场，旧记录置 `superseded` 保留审计，自动开出保险/安装团队/公开展示许可三项连带事项；**已发生的运输与展出记录不可重排覆盖**。
- **处置方案**：作品损坏、权利撤回、场地关闭生成带步骤、证据事件与替代方案快照的可审计方案。
- **跨时区**：提交带偏移量，按展馆 IANA 时区落位，保留当地挂钟表示。
- **幂等**：院校 `(school_ref, batch_ref)` 批量重传与事件 `event_id` 重放均不产生第二次写入。
- **查询**：作品完整展陈轨迹；场地时段内的安装前置项、未解决风险与可替代方案。

## 运行

```sh
make test      # 全部单元与 HTTP 端到端测试
make run       # 启动服务，默认 :8080
make migrate   # 初始化本地数据目录（当前内存实现无需建表）
```

健康检查：`GET /health`。

## HTTP 接口

| 方法与路径 | 说明 |
| --- | --- |
| `POST /v1/venues` / `GET /v1/venues` | 登记/列出场地 |
| `POST /v1/equipment` / `GET /v1/equipment` | 登记/列出设备 |
| `POST /v1/batches` | 院校批量清单（幂等） |
| `POST /v1/events` | 运营事件入台账（到场/损坏/撤回/关闭/保险/许可/班组/试播） |
| `GET /v1/events?subject_ref=` | 台账查询 |
| `POST /v1/slots` | 提议排期（校验 + 生成前置项） |
| `POST /v1/slots/{ref}/confirm` | 确认排期 |
| `POST /v1/slots/{ref}/reschedule` | 临时换场（连带保险/团队/许可） |
| `POST /v1/slots/{ref}/cancel` | 取消未开始排期 |
| `GET /v1/slots/{ref}` | 排期详情 |
| `GET /v1/works/{ref}/timeline` | 作品完整展陈轨迹 |
| `GET /v1/venues/{ref}/window?start=&end=` | 场地时段视图（前置项/风险/替代方案） |
| `GET /v1/plans/{ref}` / `POST /v1/plans/{ref}/execute` | 处置方案查询/执行步骤 |
| `GET /v1/change-orders` | 换场连带事项清单 |

请求/响应示例见 `contracts/`。错误统一为 `{"error":{"code","message"}}`，校验/冲突返回 400/409，可据此向工作人员展示全部未通过项。

## 目录

- `cmd/server` 主程序（嵌入 `time/tzdata`，容器内可解析 IANA 时区）。
- `internal/domain` 领域类型与纯规则（重叠、权利窗口、时区落位、摘要）。
- `internal/store` 并发安全的内存事实库与只追加事件台账。
- `internal/service` 应用服务：批次幂等、排期生命周期、处置方案、查询。
- `internal/api` HTTP JSON 接口。
- `contracts/` 外部交换字段示例。
- `docs/` 领域约定。

配置通过环境变量传入（`PORT`），敏感值和本地数据库文件不得提交到仓库。
