# 领域约定

国际影像展陈协调器围绕影像作品、场地和展示权利保存可核对的业务记录。外部主体使用不含真实身份信息的稳定引用编号，时间采用带偏移量的 ISO 8601 字符串，材料只保存受控引用和 `sha256` 摘要。

交换事件包含 `event_id`、`source`、`source_sequence`、`occurred_at`、`received_at`、`subject_ref`、`type` 和 `payload_digest`。来源序号只在同一来源内递增，接收方必须保留原始发生时间，不得用到达时间覆盖；更小序号的迟到事件仍入账并标记 `stale_sequence`，`event_id` 重放为幂等操作，副作用不重复执行。示例内容仅用于说明字段形状，不代表真实人员、机构或业务结论。

## 核心对象

| 对象 | 编号前缀 | 关键事实 |
| --- | --- | --- |
| 作品 Work | 外部编号 | 标题、脱敏艺术家/院校引用、媒介（photo/video/book/experimental_film） |
| 组成件 Component | 外部编号 | 形态 physical/digital、运输条件、播放规格、sha256；到场与损坏状态 |
| 权利声明 Right | 外部编号 | 权利人、允许国家（`ALL` 通配）、媒介（`*` 通配）、起止日期、撤回状态 |
| 借展协议 Loan | 外部编号 | 借展窗口，结束时间即撤展时间 |
| 场地 Venue | 外部编号 | 国家、IANA 时区、接受媒介、必须满足的场地条件、关闭状态 |
| 设备 Equipment | 外部编号 | 可播放规格、可提供的场地条件、已现场试播的规格 |
| 排期 Slot | `SLOT-n` | 场地+作品+半开区间、占用的实体组成件与设备、proposed/confirmed/cancelled/superseded |
| 安装前置项 Prerequisite | `PRE-n` | 运输到场、保险、公开展示许可、安装班组、现场试播；含截止时间与依赖 |
| 处置方案 Plan | `PLAN-n` | 损坏/撤回/关闭触发，含分步步骤、证据事件与替代方案快照 |
| 换场单 ChangeOrder | `CHG-n` | 临时换场/取消对保险、安装团队、公开展示许可的连带事项 |

## 时间规则

- 所有排期区间为半开 `[start, end)`，首尾相接的两个排期不算重叠。
- 跨时区提交一律携带偏移量，系统换算到场地的 IANA 时区落位；排期同时保存瞬时值（用于冲突计算）和 `local_start/local_end` 当地挂钟字符串（用于展示与审计）。
- 院校清单的 `occurred_at` 保留院校提交时刻；系统自身生命周期事件（提议/确认/换场/取消）也写入同一本只追加台账。

## 确认与变更规则

- 提议排期即执行：实体组成件/设备重叠占用、权利地域/媒介/日期覆盖、借展窗口、场地接受媒介、场地条件被设备满足、数字件播放规格被设备支持。
- 确认时重新执行全部规则（权利可能已撤回、场地可能已关闭），且全部安装前置项必须已解决。
- 已开始的 confirmed 排期不可换场、不可取消（`past_immutable`）；运输到场等既成事实不被重排覆盖。未开始的 confirmed 排期换场时，旧记录置 `superseded` 并保留，新排期重新生成前置项，已到场实体件的运输前置项继承为已解决，同时开出保险/安装团队/公开展示许可三项连带事项。

## 幂等

- 院校批量清单以 `(source="school:<school_ref>", batch_ref)` 为幂等键；重传即使内容不同也以首次受理为准，响应中以 `digest_changed` 提示，事实库与台账不发生第二次写入。
- 运营事件以 `event_id` 去重；前置项被事件解决后记录 `resolved_by` 事件编号。

## 处置方案

- 组成件损坏：封存、报案、评估、换场、通知；损坏件不得进入新排期。
- 权利撤回：仅影响当前无其他有效声明完整覆盖的未结束排期，已结束的历史展出不受影响。
- 场地关闭：波及该场地全部未结束排期，方案含作品转移、设备回收、保险批改与许可重申。
- 替代方案在方案生成时计算快照：可承接的开放场地（媒介与权利均满足）、同院校同媒介且同期空闲的替代作品、能力相交且同期空闲的替代设备。

## 查询

- `GET /v1/works/{ref}/timeline`：作品完整展陈轨迹，合并台账事件、全部排期（含取消/被替换）与处置方案，标注不可变记录。
- `GET /v1/venues/{ref}/window?start&end`：场地时间窗内每条排期的安装前置项、未解决风险（前置项逾期、权利缺口、借展超期、损坏件、未闭环换场事项等）与可替代方案。
